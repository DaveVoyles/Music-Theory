## Plans vs ADRs

- **Plans** (`design/NNNN-…`): deliverables, deps, testing seams, issue map — what to build.
- **ADRs** (`decisions/NNNN-…`): locked technical choices and consequences — why we build it that way.

Start with [design/0001-interactive-music-theory-app.md](design/0001-interactive-music-theory-app.md) for product scope.
